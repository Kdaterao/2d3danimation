


# What is mpl_Connector?

 - mpl_Connector is a connector used to connect our brushes to mypaintlib's api



# WHY are making this connector?

 - it is pretty standard to use mypaintlib's api since they are much more fleshed out brush engine    (krita, opentoonz, ect...)

 - our main goal is NOT a painting software, but instead a more customized animation experience 
   so we really dont need to waste our time with making our own battle tested brush engine
